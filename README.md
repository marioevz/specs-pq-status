# specs-pq-status

What a post-quantum (leanSPHINCS) Ethereum account can and can't do under EIP-8141 frame transactions with [ethereum/EIPs#12616](https://github.com/ethereum/EIPs/pull/12616), and the open questions.

Rendered at https://marioevz.github.io/specs-pq-status/. The page is a single static `index.html` with no build step.
